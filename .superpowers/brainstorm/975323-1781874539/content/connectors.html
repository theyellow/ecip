⊕ Knowledge Connectors

Select which sources to support in Epic 42. Gold border = already planned for v1. Faded = no public API available.

— Tier 1: Fully Free, No Key Required —
Wikipedia
Encyclopedia · Background knowledge
FreeNo key
Clean article summaries via REST v1. Ideal for entity context seeding.
arXiv
Preprints · Physics, Math, CS, Econ
FreeNo key
2M+ preprints. Full PDFs freely accessible. 3 req/s limit.
PubMed
Biomedical literature · NCBI
FreeKey optional
36M+ citations. 10 req/s with free NCBI key. OA full-text via PMC.
Wikidata
Structured knowledge graph · Entities
FreeNo key
120M+ items. SPARQL + REST. Best for entity enrichment: authors → ORCID, orgs → ROR.
OpenAlex
Papers · Citations · Concepts · 250M+ works
FreeNo key
Successor to Microsoft Academic Graph. CC0. Covers all disciplines. Rich concept graph.
Semantic Scholar
Papers · Citations · TLDR summaries
FreeKey optional
214M+ papers. AI-generated TLDRs. Batch endpoints for 500 items at once.
Crossref
DOI metadata · Funders · Licenses
FreeNo key
140M+ DOIs. Ground truth for publication metadata. CC0. No full text.
Europe PMC
Life sciences · Text-mined entities
FreeNo key
33M+ pubs. Unique: text-mined genes, proteins, chemicals, diseases from full text.
bioRxiv / medRxiv
Biology + Medicine preprints
FreeNo key
Track when preprints get published. Version history. 30 records per call.
CORE
Full-text open-access papers · 200M+
FreeFree key
Unique: actual full text from institutional repositories. Best for RAG content extraction.
Zenodo
Papers · Datasets · Software · CERN
FreeNo key
3M+ research objects. Strong on datasets, software, gray literature. Download links.
Unpaywall
Open-access lookup by DOI
FreeEmail only
Given any DOI: is there a free legal copy? Where? 100k req/day free. Essential utility.
DOAJ
Open-access journal directory
FreeNo key
20k+ OA journals, 10M+ articles. Verify journals are genuinely OA, not predatory.
— Tier 2: Low-Cost / Freemium (Key Required) —
Exa Search
Neural web search · Content extraction
FreemiumKey req.
Meaning-based search. 1,000 req/month free. Best for finding papers not in academic DBs.
Brave Search
Independent web search · News
FreemiumKey req.
Independent index (no Google/Bing wrapper). ~1k req/month free. Good for news + recent web.
— No Public API (Consumer Tools Only) —
OceanOfPapers
Aggregator UI (no API)
No API
Wraps OpenAlex + PubMed + arXiv. Accessing those directly gives same data.
Daily Academic
Email digest (no API)
No API
Personalized paper discovery. No programmatic access.
ResearchPod
AI audio summaries (no API)
No API
Consumer app. €9.99/mo premium. No connector possible.
