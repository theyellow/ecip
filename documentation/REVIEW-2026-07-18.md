## 3. New Module: emcip-knowledge-engine

**Port**: 9088 | **Stack**: Spring Boot + JPA + JDBC + Kafka | **DB**: PostgreSQL + pgvector + Apache AGE

This is the largest single module in the project (111 source files, 51 test files) and represents a sophisticated knowledge management platform.

### 3.1 What It Does

- Ingests documents from URLs, file uploads, and Kafka messages (Apache Tika for PDF/DOCX/HTML)
- Extracts entities and relationships using LLM-based NLP
- Performs 4-tier entity resolution (exact match, alias, embedding similarity, new node)
- Maintains a knowledge graph via Apache AGE (property graph on PostgreSQL)
- Provides hybrid vector/graph search (pgvector + AGE combined)
- Orchestrates deep research workflows with agent-based question decomposition
- Integrates with 14 external knowledge sources (PubMed, Arxiv, Wikipedia, Wikidata, etc.)

### 3.2 Architecture Strengths

- **Clean connector registry pattern**: `KnowledgeConnector` interface with 14 implementations, Spring-managed discovery
- **Resilience**: Circuit breakers on LLM calls (embed + extract), DLQ for Kafka, graceful degradation when embeddings fail
- **Tenant isolation**: Hibernate `@Filter` + AOP aspect on all multi-tenant entities
- **Excellent test coverage**: 51 test files covering connectors, services, repositories, controllers, and integration tests using Testcontainers with pgvector
- **Configurable thresholds**: merge (0.92), flag (0.80), chunk size (600 tokens), embedding dimension (1024) all via properties

### 3.3 Issues Found

| # | Issue | Severity | Location | Detail |
|---|-------|----------|----------|--------|
| KE1 | **Apache AGE at RC version** | MEDIUM | `docker/postgres-knowledge/Dockerfile` | Uses `v1.5.0-rc0` (release candidate). Production should use stable release. |
| KE2 | **Synchronous research loop** | MEDIUM | `ResearchAgentService.java:30-32` | Research sessions run synchronously within a single transaction. Pause/resume cannot interrupt mid-execution. Documented TODO for Epic 27B. |
| KE3 | **Hardcoded cost constant** | LOW | `ResearchAgentService.java` | `COST_PER_ITERATION_USD = 0.01` is hardcoded. Should be configurable per tenant or model. |
| KE4 | **No fallback on embedding failure** | LOW | Vector search path | If embedding generation fails (circuit breaker open), vector search returns empty — no fallback to keyword/full-text search. |
| KE5 | **ExecutorService per regex call** | LOW | Moderation's `RuleEvaluationService` | Creates new `Executors.newSingleThreadExecutor()` per evaluation. Should reuse a thread pool. |

### 3.4 Verdict

The knowledge-engine is well-architected with production-grade patterns. Its test coverage (51 files / 111 source = 46% file ratio) is the best in the project. The connector registry, entity resolution pipeline, and hybrid search are sophisticated and well-implemented. No critical issues.

- **CORS properly scoped**: configurable origins, specific methods, no wildcard
- **Swagger disabled in prod**: `application-prod.yml` disables OpenAPI endpoints

## 7. Architecture Review

- **Event-driven pipeline**: Clean unidirectional Kafka flow with 11+ topics, no circular dependencies
- **Observability stack**: Prometheus + Grafana + Loki + Tempo with OpenTelemetry instrumentation on all services
- **GraalVM native support**: 3 services with native image builds, version pinned at 25.0.1 with documented rationale
