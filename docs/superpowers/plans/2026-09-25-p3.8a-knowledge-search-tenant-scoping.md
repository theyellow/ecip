# P3.8a Knowledge Search Tenant Scoping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Knowledge search never returns another tenant's rows: tenant set → own + global, tenant null → global only; and admin-api's proxy binds the tenant from the caller's identity instead of the request body.

**Architecture:** Three knowledge-engine search queries adopt one predicate (`tenant_id = ? OR tenant_id IS NULL` / `tenant_id IS NULL`). admin-api's `KnowledgeSearchProxyController` resolves the tenant from the Reactor context `AdminTenantContextFilter` already populates, via a small `KnowledgeTenantResolver`, and rewrites the forwarded request.

**Tech Stack:** Java 21, Spring Boot 4, JdbcTemplate + pgvector, Apache AGE (Cypher), Spring WebFlux (admin-api), Jackson 3 (`tools.jackson`), JUnit 5, AssertJ, Testcontainers (`ghcr.io/theyellow/ecip/postgres:16`), OkHttp `mockwebserver3`.

**Spec:** `docs/superpowers/specs/2026-09-25-p3.8a-knowledge-search-tenant-scoping-design.md`

## Global Constraints

- Tenant rule, every knowledge **search** query: tenant set → `tenant_id = :t OR tenant_id IS NULL`; tenant null → `tenant_id IS NULL`. Never unfiltered.
- `GraphNodeEmbeddingRepository.findNearestNeighbour` is **not** changed.
- "Global" = `tenant_id IS NULL` (SQL) / property absent (AGE — `createNode` omits `tenant_id` when null).
- Every new assertion must be observed failing once before it counts (project verification rule).
- Build with JDK 21: `export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64` (spotless crashes on the default JDK 25).
- `mvn spotless:apply` before every commit; `pmd:check` before the PR (not part of `verify`).
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- Embedding dimension in tests: `@Value("${knowledge.embedding.dimension}")` (1024).
- Test isolation: the knowledge-engine Testcontainers DB is shared by all test classes in a run. Seed with a
  distinctive embedding direction (index `777` = 1.0) and assert on the ids you seeded, not on totals.

```java
package io.emcip.admin.api.controller;

import io.emcip.common.tenant.ReactorTenantContext;
import java.util.UUID;
import reactor.util.context.ContextView;

/**
 * Decides which tenant a knowledge request runs as (P3.8a). The caller's identity decides, never a
 * tenant-bound caller's request: {@code AdminTenantContextFilter} has already bound the JWT tenant
 * (or an ADMIN's {@code X-Tenant-ID} header) into the Reactor context.
 */
final class KnowledgeTenantResolver {

    private KnowledgeTenantResolver() {}

    /**
     * @param requested the tenant the request names (body or query), may be null
     * @return the tenant to forward, or null for global-only knowledge
     * @throws IllegalArgumentException if an ADMIN in admin mode names something that is not a UUID
     */
    static String resolve(ContextView ctx, String requested) {
        String bound = ReactorTenantContext.getTenantId(ctx);
        if (bound != null) {
            return bound;
        }
        if (ReactorTenantContext.isAdminMode(ctx) && requested != null && !requested.isBlank()) {
            return UUID.fromString(requested).toString();
        }
        return null;
    }
}
```

```java
    @PostMapping("/search")
    @PreAuthorize("hasAuthority('KNOWLEDGE_READ')")
    public Mono<ResponseEntity<String>> search(@RequestBody String body) {
        ObjectNode request;
        try {
            if (!(objectMapper.readTree(body) instanceof ObjectNode node)) {
                return Mono.just(ResponseEntity.badRequest().<String>build());
            }
            request = node;
        } catch (JacksonException e) {
            return Mono.just(ResponseEntity.badRequest().<String>build());

        return Mono.deferContextual(
                ctx -> {
                    String tenant;
                    try {
                        JsonNode requested = request.get("tenantId");
                        tenant =

                                        ctx,
                                        requested == null || requested.isNull()
                                                ? null
                                                : requested.asString());

                        return Mono.just(ResponseEntity.badRequest().<String>build());
                    }
                    if (tenant == null) {
                        request.putNull("tenantId");
                    } else {
                        request.put("tenantId", tenant);
                    }
                    return knowledgeWebClient
                            .post()
                            .uri("/api/knowledge/search")
```
